# AimGo UI 样式重构计划（V1）

> 创建时间：2026-03-05  
> 目标：统一圆角、字体层级与控件密度，解决“小屏换行拥挤”和“视觉风格不一致”问题。

---

## 1. 问题摘要

- 圆角半径分散（4/6/8/10/12 混用），页面风格不统一。
- 全局缺少按钮、输入框、卡片、分段控件的统一主题配置。
- 多处硬编码小字体（如 `fontSize: 10`）与固定宽度导致拥挤。
- 多个页面使用横向控件（按钮组 / SegmentedButton）在 360dp 下易挤压。

---

## 2. 重构顺序（执行策略）

### Phase A：全局样式基线（优先）

- [x] 建立统一文本层级（`title/body/label`）与行高
- [x] 统一核心控件圆角策略（小/中/大三档）
- [x] 统一按钮、输入框、卡片、SegmentedButton、Chip、ListTile 主题
- [ ] 补充页面级间距 token（后续可抽离到常量）

### Phase B：高风险拥挤页面（第二步）

- [x] 首页：快捷操作按钮在小屏自动纵向堆叠，减少挤压
- [x] 首页：图表文字改为跟随全局 `labelSmall`，去硬编码字号
- [x] 分析页：顶部范围 SegmentedButton 支持横向滚动
- [x] 分析页：图表标签与热力图小时标签改为主题字体
- [x] 设置页：语言/主题 SegmentedButton 支持横向滚动
- [x] 历史页：视图切换 SegmentedButton 支持横向滚动
- [x] 专注页：模式切换 SegmentedButton 支持横向滚动
- [x] 目标页：任务行压缩与溢出控制，缓解标题换行拥挤

### Phase C：一致性收口（第三步）

- [ ] 目标页 Header 紧凑化（小屏下减少标题挤压）
- [ ] 历史/目标/首页卡片内边距与纵向节奏统一
- [ ] 复核深色模式对比度与信息层级
- [ ] 360dp + 中英双语 + 字体放大场景走查

---

## 3. 验收标准

- [ ] 360dp 宽度下关键主流程页面无明显文字拥挤与异常换行
- [ ] 圆角风格统一，不再出现“同层级组件圆角不一致”问题
- [ ] 所有页面不再依赖零散硬编码小字号（优先使用主题文本）
- [ ] `flutter analyze` 与 `flutter test` 通过

---

## 4. 当前进度说明

- 已完成 Phase A 及 Phase B 的第一批改造（全局主题 + 高风险页面）。
- 下一步将按 Phase C 做一致性收口和 360dp 专项回归。
