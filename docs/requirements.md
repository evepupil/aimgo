# AimGo 应用需求文档

## 1. 通用需求

- 灰黑+白简约风格设计
- 底部4个导航栏：首页、目标、专注、我的
- 响应式设计，适配不同尺寸的移动设备
- 顶部header栏支持滚动隐藏/显示效果
- 页面切换时保留平滑过渡动画

### 1.1 多语言支持

- 支持中文和英文两种语言
- 可在设置中切换语言
- 所有界面文本、提示信息、按钮标签等均支持多语言
- 根据系统语言自动选择默认语言

### 1.2 主题设置

- 支持浅色和深色两种主题
- 浅色主题：以白色为主要背景色，黑色文本
- 深色主题：以灰黑色为主要背景色，白色文本
- 可在设置中手动切换主题
- 支持跟随系统主题自动切换
- 主题切换时保留平滑过渡动画

### 1.3 核心设计理念

AimGo 的核心驱动力是**用明确的时间目标驱动用户完成任务**。通过实时可见的进度反馈，利用蔡格尼克效应（未完成事项的心理张力）推动用户持续投入，同时通过累计专注时长的成就感来正向激励。

#### 1.3.1 三级层级模型

采用 **目标（Goal）→ 里程碑（Milestone）→ 任务（Task）** 三级层级：

- 每个层级都有**预估时间**
- 时间层层关联：**目标预估时间 = 子里程碑预估时间之和 = 每个里程碑下任务预估时间之和**
- 用户创建/修改子级的预估时间时，父级预估时间自动重新汇总

#### 1.3.2 时间进度与完成状态

**时间进度**和**完成状态**是两个独立的维度：

**时间进度（自动计算）：**
- 任务时间进度 = 该任务累计有效专注时间 / 预估时间
- 里程碑时间进度 = 子任务累计有效专注时间之和 / 里程碑预估时间
- 目标时间进度 = 子里程碑累计有效专注时间之和 / 目标预估时间
- 时间进度**可以超过 100%**（用户可以在任何层级投入超过预估的时间）

**完成状态：**
- **任务**：用户手动勾选完成（手动勾选更有参与感和成就感）
- **里程碑**：所有子任务勾选完成后，自动标记为完成
- **目标**：所有子里程碑完成后，自动标记为完成

两个维度独立存在：任务可以时间进度 50% 但已勾选完成（提前完成），也可以时间进度 150% 但未勾选完成（超时仍在进行）。

#### 1.3.3 有效专注时间

用户每次专注结束后进行自评，给出一个效率系数（0% ~ 100%）：

- **有效专注时间 = 实际专注时长 × 效率系数**
- 有效专注时间才计入任务的时间进度
- 未自评时默认使用 60% 的效率系数

#### 1.3.4 进度条超时视觉

当时间进度超过 100% 时：
- 进度条正常填充至 100% 位置
- 超出部分使用渐变色过渡（正常色 → 橙色），直观提示用户已超出预估
- 进度条旁的文字显示实际时间（如 `3h / 2h`）

## 2. 目标页面

### 2.1 页面结构

- 顶部header栏包含"我的目标"标题和操作按钮（搜索、筛选、菜单）
- 顶部header栏目标切换按钮，点击当前的目标切换抽屉
- 直接显示当前选中目标的里程碑列表，无需显示目标卡片
- 右下角悬浮添加按钮

### 2.2 目标切换抽屉

- 从底部向上滑出的抽屉式设计
- 显示所有目标及其进度
- 当前选中的目标显示勾选标记
- 底部提供"添加新目标"按钮，和管理目标按钮
- 管理目标按钮点击后目标项卡片右侧出现编辑和删除按钮
- 点击目标项会更新当前显示的里程碑列表

### 2.3 搜索功能

- 点击搜索按钮后，整个header栏变为搜索框
- 搜索框左侧显示搜索图标
- 搜索框右侧显示关闭按钮
- 点击关闭按钮恢复正常header
- 搜索范围包括目标、里程碑和任务
- 搜索匹配到的字符进行高亮（或者其他可以直接看到的方式）

### 2.4 里程碑展示

- 卡片式设计，显示里程碑标题
- 右侧显示任务数量（已完成/总数）和时间进度信息
- 进度条显示时间进度（有效时间 / 预估时间），超过 100% 时渐变为橙色（见 1.3.4）
- 进度条下方显示已投入有效时间 / 预估时间
- 当所有子任务勾选完成后，里程碑自动标记为完成状态
- 点击里程碑可展开/收起任务列表
- 展开/收起动画平滑过渡

### 2.5 任务展示

- 任务与里程碑文本对齐
- 使用分割线分隔不同任务
- 左侧显示完成状态图标：
  - 未完成：圆圈，圈圈边缘填充绿色表示时间进度（有效时间 / 预估时间）
  - 已完成：勾选图标（用户手动勾选）
- 右侧显示已投入有效时间 / 预估时间
- 已完成的任务文本显示删除线和灰色

## 3. 专注页面

### 3.1 页面结构

- 顶部header栏包含"专注"标题和操作按钮（历史、设置）
- 专注模式切换Tab（番茄钟/自由专注）
- 专注上下文信息（目标>里程碑>任务）
- 中央计时器区域
- 底部控制按钮区域

### 3.2 专注模式

- 番茄钟模式：默认25分钟，完成后提示休息
- 自由专注模式：从0开始计时，无预设时长
- 通过顶部Tab切换不同模式

### 3.3 计时器功能

- 时钟圆圈边缘显示进度（而非填充整个圆形）
- 番茄钟模式：点击时钟区域弹出时间选择对话框
- 自由专注模式：点击时钟区域不弹出时间选择对话框
- 番茄钟模式提供预设时间（25分钟、45分钟、60分钟、90分钟）
- 中央显示剩余时间（番茄钟）或已计时时间（自由专注）

### 3.4 专注目标选择

- 专注时可选择目标、里程碑或任务作为专注对象
- 默认选择目标页面当前选择的目标
- 目标选择路径：目标 > 里程碑 > 任务
- 选择后显示完整路径，以便用户了解当前专注的上下文

### 3.5 控制按钮

- 未开始专注时：只显示"开始专注"按钮
- 开始专注后：显示"暂停"和"终止"按钮
- 暂停后可继续专注
- 终止后重置计时器

### 3.6 完成流程

- 专注结束后弹出提示
- 引导用户进行自评（跳转到自评页面）
- 记录专注时间和相关数据

## 6. 专注历史页面

### 6.1 页面结构

- 顶部header栏包含"专注历史"标题、返回按钮和操作按钮（搜索、筛选）
- 视图切换Tab（时间轴/日历）
- 筛选区域，包含目标选择和时间范围选择
- 历史记录列表（时间轴视图）或日历视图

### 6.2 导航方式

- 从专注页面右上角的历史按钮进入
- 返回按钮返回到专注页面
- 默认显示当前目标界面选中目标的专注记录

### 6.3 筛选功能

- 目标筛选：可选择全部或特定目标
- 时间范围筛选：全部、今天、本周、本月、自定义
- 自定义时间范围：可选择开始日期和结束日期
- 筛选选项点击即时生效

### 6.4 搜索功能

- 点击搜索按钮可输入关键词搜索
- 搜索范围包括任务名称、备注等
- 支持模糊搜索

### 6.5 时间轴视图

- 按日期分组：今天、昨天、本周、上周等
- 垂直时间轴设计，左侧显示日期点和连接线
- 每条记录显示：
  - 任务名称
  - 专注时间段
  - 目标和里程碑路径
  - 专注时长
  - 专注效率
  - 有效专注时长（专注时长 × 专注效率）
  - 专注状态（已完成/已放弃）
- 卡片式设计，清晰展示每条记录信息

### 6.6 日历视图

- 月历格式显示，支持月份切换
- 有专注记录的日期显示指示点
- 当前日期高亮显示
- 选中日期边框高亮
- 点击日期显示该日的专注记录列表
- 日期记录列表与时间轴视图中的记录卡片样式一致

## 7. 自评页面

### 7.1 页面结构

- 顶部header栏包含"专注自评"标题和关闭按钮
- 本次专注会话摘要信息
- 专注效率评估区域，包含滑条和预设值
- 有效专注时间显示
- 备注输入框
- 提交按钮和跳过按钮

### 7.2 专注效率评估

- 使用滑条（slider）进行效率评估，范围0-100%
- 提供5个预设值：20%、40%、60%、80%、100%
- 可以通过点击预设值或拖动滑条来设置效率
- 当前选中的效率值高亮显示
- 实时显示对应的有效专注时间（专注时长 × 效率）

### 7.3 时间计算逻辑

详见核心设计（1.3 节），以下为自评流程中的具体应用：

- 有效专注时间 = 专注时长 × 专注效率系数
- 提交后，有效时间累加到对应任务的已投入有效时间
- 任务、里程碑、目标的时间进度自动重新计算
- 时间进度可超过 100%，不做上限截断

### 7.4 功能需求

- 自动填充本次专注的相关信息（任务、时间等）
- 提交时保存专注效率和有效时间
- 更新相关任务、里程碑和目标的进度
- 备注信息支持多行文本输入
- 提供跳过功能，跳过时使用默认效率值（60%）计算有效时间
